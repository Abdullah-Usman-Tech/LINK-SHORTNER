# Minimalist Slate & Monochrome Tech Style Skill

Apply this exact design aesthetic whenever generating web components, pages, or entire projects.

## Core Visual Identity
- **Canvas / Background**: Off-white light slate canvas (`bg-gray-50` / `#f8fafc`).
- **Cards & Containers**: Pure white (`bg-white`), thin crisp borders (`border border-gray-200`), rounded corners (`rounded-xl` or `rounded-2xl`), soft shadows (`shadow-sm`, `shadow-2xl` for modals).
- **Typography**: Inter / system-ui font. Headings: `text-2xl font-bold text-gray-900`. Labels/Eyebrows: `text-xs font-medium uppercase tracking-wider text-gray-400`. Brand tag: `✦ BrandName` with `tracking-widest uppercase text-gray-700`.
- **Primary Actions**: Dark charcoal buttons (`bg-gray-900 text-white font-semibold hover:bg-gray-700 active:scale-95 transition-all duration-150 rounded-lg`).
- **Secondary Actions**: Light bordered outline buttons (`border border-gray-200 text-gray-600 hover:bg-gray-50 transition-colors rounded-lg`).
- **Form Controls**: `h-11 px-3.5 rounded-lg border border-gray-200 bg-gray-50 text-sm text-gray-800 placeholder-gray-300 outline-none focus:border-gray-400 focus:bg-white focus:ring-2 focus:ring-gray-100 transition-all`.
- **Status Pills**: Soft tinted badges (`bg-emerald-50 text-emerald-700 border border-emerald-200` for active/success).
